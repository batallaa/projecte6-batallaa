# 📚⚖️ T11: Comparativa Moodle vs Canvas LMS

## 📝 Breu Descripció

Un cop completades les tasques T09 i T10 (desplegament i configuració de Moodle i Canvas), cal elaborar una **comparació tècnica, visual i argumentada** entre les dues plataformes LMS.

Aquesta comparativa **NO pot ser una simple llista**, sinó un **estudi crític i reflexiu**, amb anàlisis i diagrames professionals creats amb **Napkin.ai**.

L’entrega final serà **un únic PDF** amb tots els continguts.

### 🔧 1. Facilitat d’instal·lació  
### 🏗️ 2. Arquitectura tècnica  
### 📈 3. Corba d’aprenentatge  
### 🏫 4. Creació de cursos  
### 📝 5. Gestió d’activitats  
### 📊 6. Sistema d’avaluació  
### 🎨 7. Personalització visual
